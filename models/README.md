# Saved Model Artifacts

These files are generated by running `python -m src.train` from the
repository root. They are committed to this repo so the project can be
evaluated without re-running training, but they are fully reproducible.

| Model / Artifact | File(s) |
|---|---|
| `preprocessor.joblib` | Fitted `sklearn.compose.ColumnTransformer` — one-hot encoder for `StudentAbsenceDays` (a behavioral/attendance field) + `StandardScaler` for the four numeric engagement features. **Demographic/contextual fields are NOT part of this transformer at all** (mentor-corrected feature scope — see README Section 4a). Fitted on the TRAIN split only. |
| `final_kmeans_model.joblib` | The final, selected clustering model: `sklearn.cluster.KMeans(n_clusters=4, random_state=42)`, fitted on the preprocessed TRAIN split. |
| `pca_projector.joblib` | `sklearn.decomposition.PCA(n_components=2)` fitted on the TRAIN split, used only to generate the 2D cluster visualization — it is not part of the clustering decision itself. |
| `model_metadata.json` | Everything needed to interpret the model: the k-selection reasoning (including the honest disclosure that k=2 had the best pure silhouette score), the cluster → learner-profile name mapping, per-k silhouette scores, stability (ARI) results, cluster feature means, and the DBSCAN/Agglomerative comparison results. |

## Human-readable model contents (no code required)

The three `.joblib` files above are binary (Python pickle) files — they can't
be opened directly in a text editor or browser. To make their contents fully
visible without running any code, `src/export_model_readable.py` reads them
and writes out two read-only, plain-text exports of everything meaningful
inside them:

- **[`model_contents_human_readable.md`](model_contents_human_readable.md)** —
  open this directly on GitHub or in any text editor. Shows the exact
  categories the encoder learned, the scaler's mean/std per feature, the
  K-Means cluster count, random seed, iterations, inertia, and the
  cluster → learner-profile mapping.
- **`model_contents_human_readable.json`** — the same information as
  structured data, including the full numeric cluster-centroid and PCA
  component arrays, for anyone who wants the raw numbers.

These exports do **not** modify, retrain, or alter the trained model in any
way — they are a read-only view generated from the existing `.joblib` files.
Regenerate them any time with:

```bash
python -m src.export_model_readable
```

## Why K-Means (and not Agglomerative or DBSCAN) is the artifact saved here

All three algorithms are trained and logged to MLflow in `src/train.py` for
comparison. Only K-Means is saved as the deployable artifact because:

1. It is the only one of the three with a native `.predict()` method, so it
   can assign a **brand-new, unseen student** to a cluster without being
   refit — Agglomerative Clustering and DBSCAN can only label the points they
   were originally fit on. This directly matters for the Acceptance
   Criterion: *"The solution can process previously unseen input."*
2. Across 5 random seeds, K-Means produced highly stable cluster assignments
   (mean pairwise Adjusted Rand Index ≈ 0.98 — see `model_metadata.json`).

## Reproducing these files

```bash
pip install -r requirements.txt
python -m src.train      # regenerates everything in this folder + reports/figures
python -m src.evaluate    # evaluates the saved model on the held-out test split
python -m src.export_model_readable   # regenerates the human-readable exports above
```
